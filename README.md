# Projet de détection de spam par email

**Objectif :** Développer un modèle de classification automatique capable de distinguer les emails légitimes des emails indésirables (*spams*) à l'aide de techniques de Deep Learning.

Ce projet a pour objectif de mettre en pratique et d'approfondir mes connaissances en Machine Learning et Deep Learning, notamment dans le domaine du traitement automatique du langage naturel (NLP).

Le projet s'appuie sur TensorFlow et consiste à explorer différentes étapes de préparation et de traitement des données textuelles, puis à construire un modèle de classification basé sur une couche d'Embedding et un réseau de neurones récurrent de type LSTM.

**## Installation**

```bash
python -m venv .venv

# Activation de l'environnement
# Linux / macOS
source .venv/bin/activate

# Windows
.venv\Scripts\activate

# Installation des dépendances
pip install -r requirements.txt
```
